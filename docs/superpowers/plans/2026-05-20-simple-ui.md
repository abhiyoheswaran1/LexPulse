# Simple UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a switchable Simple UI across the core LexPulse product while keeping the existing UI as the default Advanced experience.

**Architecture:** Keep existing routes unchanged. Add `/simple` route family, a route-aware app chrome, and small Simple-mode components. Put deterministic status and reason logic in `src/lib/simple-ui.ts` so it can be tested without rendering pages.

**Tech Stack:** Next.js App Router, React server components, TypeScript, TailwindCSS, Prisma, Vitest.

---

## File Structure

- Create `src/lib/simple-ui.ts`: pure status, reason, and sector summarization helpers.
- Create `src/lib/__tests__/simple-ui.test.ts`: unit tests for Simple-mode classification.
- Create `src/components/AppChrome.tsx`: route-aware Advanced and Simple app shells.
- Modify `src/app/layout.tsx`: delegate shell rendering to `AppChrome`.
- Create `src/components/simple/SimpleUI.tsx`: shared cards, pills, tabs, and page header.
- Create `src/app/simple/page.tsx`: Simple queue and map dashboard.
- Create `src/app/simple/search/page.tsx`: Simple search page.
- Create `src/app/simple/alerts/page.tsx`: Simple alerts page.
- Create `src/app/simple/companies/[id]/page.tsx`: Simple company brief.
- Modify `src/app/companies/[id]/page.tsx`: add link to Simple brief.
- Modify `.gitignore`: ignore `.superpowers/` preview artifacts.
